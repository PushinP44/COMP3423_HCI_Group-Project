# Meeting Notes

One file per sync, named `YYYY-MM-DD.md`. Keep it short: attendees, decisions made, action items with owner + due date. This is process evidence — it corroborates the workload declaration and the task log if anyone's contribution is ever questioned.

Suggested cadence: weekly 20-min sync (per the project plan, owned by Member 1).

## Template for each note

```markdown
# YYYY-MM-DD sync

**Attendees:** [names]

**Decisions:**
- ...

**Action items:**
- [ ] [task] — @[member] — due [date]
```
