# Redesign Screenshots

Before/after captures from the actual Figma prototype (export from Figma, don't screenshot a design tool mockup that isn't in the real prototype file — the prototype quality rubric item checks the live Figma link, so what's here should match it).

## Conventions

- Filename: `feature-N_screen-name_v{1|2}.png` (e.g. `feature-3_confirm-transfer_v2.png`) — the `v1`/`v2` suffix is your iteration evidence trail; keep both versions, don't overwrite.
- Pair every "after" image here with the matching "before" image's filename from `../existing-app/` in the report text, so the before/after comparison is easy for markers to follow.
