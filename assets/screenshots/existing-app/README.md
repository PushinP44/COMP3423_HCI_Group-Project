# Existing App Screenshots

**Real screenshots only — from the actual installed app.** Markers explicitly check that "before" screenshots are not AI-generated mockups. Fabricating or AI-generating these is an academic integrity risk, not just a rubric miss.

## Conventions

- Filename: `YYYY-MM-DD_screen-name_deviceOS.png` (e.g. `2026-09-23_transfer-confirmation_ios.png`) — the date is part of your evidence trail for genuine process work.
- Redact sensitive real data (account numbers, real balances) before adding to this repo — crop or blur, don't fabricate fake numbers that look real (just use obviously placeholder values like "•••• 1234" via the OS's own privacy mode if the app has one, or blur).
- One screenshot per problem is often not enough — capture the full flow (before, during, error state) where relevant.
